# ドーパミン枯渇の設定の分解と、GPiの発火率を下げる変化の探索（事前登録）

[ホールドアウト検証](../heldout/RESULTS.md)では、凍結した3モデルがPD状態でGPiの発火率の上昇を予測し、データの大きな低下と逆向きだった。[食い違いの検討](../heldout/DISCREPANCY.md)では、原因がモデル間の違いではなく、共通するドーパミン枯渇の設定にあると考えた。ここでは新しい外部データを使わずに、2つの問いを調べる。結果はすべてモデルについての仮説で、検証には数えない。

1. 設定のどの要素（D1の静止電位 −4 mV、D2の静止電位 +5.5 mV、GPe→STNの重み1.5倍）がGPiの上昇を生むか。
2. どのような変化を加えるとGPiの発火率が下がるか。原著が挙げる「出力ニューロン自身の興奮性の低下」をGPiの静止電位の低下（−2、−4、−6、−8 mV）で表し、あわせてGPiへの入力経路の重みを変える。

## 設計（[`protocol.json`](protocol.json)。この文書とコードは実行前にコミットした）

- 凍結した3モデル（既定LIF、段階2、段階4A）
- 16条件：正常、枯渇の設定すべて、要素を1つだけ入れる3条件、1つだけ抜く3条件、GPiの静止電位を下げる4条件、GPiへの入力を変える4条件（D1→GPi 2倍、GPe→GPi 2倍・0.5倍、STN→GPi 0.5倍）
- 新しい12シード（2473〜2591）。条件どうしで雑音とグラフを共有する
- 30.5秒の自発活動（最初の0.5秒を除く）を、[ホールドアウト検証](../heldout/PROTOCOL.md)と同じ1秒区間の関数で評価する。GPiは発火率・CV・振動指数、GPe・STN・D1・D2は発火率
- 効果はシードごとの「条件 − 正常」（細胞の中央値の差）。12シードの再抽出で95%区間

## 読み方

- 要素の寄与は、1つだけ入れた条件と、「すべて − 1つだけ抜いた条件」で読む
- 区間が0より下で、平均が −1 Hz以下なら「GPiを下げる」とする（段階4Bとホールドアウト検証と同じ基準）
- DANDI:000947の低下の大きさに合う設定は、使用済みのデータへの当てはめであり、検証には数えない
- 将来、GPiの発火率以外でも仮説を確かめられるよう、各条件のGPe・STNの発火率とGPiの規則性も報告する

```powershell
python -m depletion.run --out depletion_run
python -m depletion.analyze depletion_run
```
