# 併存するGPi機構の強度を未知の疑似回路から推定する

[前段階の結果](../partial_block/RESULTS.md)を受けて、GPi細胞自身のバイアス低下（H1）とGPe→GPiの抑制増強（H2）を同時かつ独立に動かす。推定対象は入力した2つの設定値の強度。発火率低下を原因別のパーセントに分配する実験ではない。生体記録は使用しない。

**設計と分割**　入力の範囲をどちらも0〜1とする。H1は各モデルの前段階の補間済みバイアスに強度を掛け、H2はGPe→GPiの重みを1＋強度倍にする。既定の枯渇設定を共通に使う。各回路は1,000細胞、観測対象は無作為に選んだGPiの24/180細胞。同じ標本の測定は同じ細胞で行う。訓練には16配線シード・各強度0/0.5/1の全組合せ・遮断25/50/75%。評価には別の16シード・各強度0.125/0.375/0.625/0.875の全組合せ・遮断35/65%。ラベルも遮断率も訓練格子の間の値。全モデルに同じ分割を使い、評価結果で再学習・調整しない。独立な評価単位はシード。

**模擬測定**

1. 回路内の発火率。遮断前と、GPiに入る負の重みを一律に減衰させた後で、細胞別発火率の中央値を測る。各測定3秒、最初の0.5秒を除外。前後は別の雑音試行。推定器には遮断前と応答差を渡す。
2. 細胞の入出力応答。GPiへのシナプス伝達をすべて除き、バイアスに −2 mV、+2 mV相当の駆動を別試行で加え、2水準の発火率を測る。モデル内の駆動単位であり、生体の注入電流への換算は仮定しない。
3. 経路の応答。GPe細胞の30%を各1回発火させたときの、GPiの閾値・リセットを止めた受動膜での電位応答を計算する。12回の刺激、0〜2 msの発火時刻のずれ、各試行・各細胞・時点に標準偏差1.5 mVの独立な計測雑音を仮定。前後は同じ細胞群・刺激列で、計測雑音は独立。刺激前平均との差をとった平均波形の最も深い過分極の大きさをピークとし、遮断前ピークと「1 − 遮断後/遮断前ピーク」を使う。比は0〜1に丸め、遮断前振幅が0.000001 mV以下なら比は0.5とする。この測定にはGPe入力だけを刺激・記録できるという仮定がある。
4. 配線シード内では、強度だけを変えた反実仮想条件に共通の雑音・細胞・刺激列を使う。条件数を個体数として扱わない。GPiに出力辺がない性質を使って上流のスパイク列を再利用し、到着遅延・結合強度を保ってGPiに入力する。全回路を直接計算する照合も行う。

**推定と判定**　事前指定の各測定セットにつき、訓練データで標準化した特徴の1次項・2次項・交互作用から、2つの強度をリッジ回帰で推定（切片は無罰則、係数の二乗和の重み1、予測は0〜1に制限）。真の遮断率を与えるセットは参考の上限比較用で、主判定には使わない。定数0.5の予測、発火率だけ、遮断率の推定値追加、細胞入出力追加、経路応答追加、両測定追加を同じ評価例で比較する。

主判定は各モデル内。両測定を加えたとき、(1) H1とH2それぞれの平均絶対誤差（MAE）が0.15以下、かつ (2) 発火率のみからの2強度平均MAEの改善が、シードを対応付きで1万回再抽出した95%区間の下限で0.025を超えれば通過。評価条件は等加重。補助解析では、残り2モデルだけを訓練に使い、未知のモデルおよび未知の配線シードで同じ指標を測る。ここでのH1の1単位はモデルごとに異なるmVに対応する。遮断率の計測誤差も別に報告する。すべての仮定とシードは [protocol.json](protocol.json) に固定した。
