# 独立した対照8回路を使う較正

第一実験の「未訓練のモデル形式への転用で精度が下がった」という結果を見て追加する別の予測試験。新しい16配線シードを評価に留保し、その出力を得る前に方法を固定する。第一実験の評価例には採点し直さない。

各対象モデルについて、既定の枯渇条件にH1・H2を追加していない別の8回路を対照とする。正常個体のデータではない。対照でも評価でも、同じ24細胞の測定法を使用する。評価側には別標本のH1とH2を独立に4水準ずつ与える。推定器が読むのは、シナプス入力を除いたGPiの2駆動水準の発火率と、経路を遮断する前のGPe誘発電位ピーク。配線図、真の強度、モデル形式ラベル、遮断率を特徴として与えない。どの対照標本を較正に使うかは既知とする。

対照8回路の平均を L、U（低・高駆動発火率）、P（ピーク）とする。評価側の値を l、u、p とし、同じ推定式を2通りの対照に適用する。

- H1のバイアス低下量（mV）は、平均発火率の差 [(L−l)+(U−u)]/2 を、対照で測った傾き (U−L)/4 で割る。物理量での共通範囲0〜6 mVに制限する。
- H2の増強分は p/P−1 とし、0〜1に制限する。
- 対象と同形式の対照8回路と、他形式2種類から各4回路（事前のシード順で先頭4）の計8回路を比較する。2種類の別形式が同一シードを使うため、その再抽出はペアにする。回帰の再訓練・結果を見た係数調整は行わない。

H1はmVのMAEと、採点時だけモデル固有のH1最大強度で割ったMAEを併記する。主判定は形式ごとに、同形式対照でH1・H2双方の範囲換算MAEが0.15以下、かつ他形式対照からの両者平均の改善の95%区間下限が0.025を超えること。区間は評価16シードを共通に再抽出し、対照8シードも再抽出する。比較側の2形式については先頭4シードをペアで再抽出する。同形式対照と他形式対照の同じ配線シードによる相関を保つため、同形式側は先頭4・後半4に層別し、先頭4の再抽出を他形式側と共有する。1万反復。人工的にH1=H2=0と分かる対照を別標本で用意できる場合の試験であり、実組織で同条件を確保できるかは別問題。
