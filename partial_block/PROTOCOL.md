# GPiへの抑制入力を段階的に弱めるモデル実験

凍結モデルではドーパミン枯渇時のGPi発火率の向きが外れた。[前段階](../depletion/RESULTS.md)で残った2つの仮説を、同じ発火率から出発させて比較する。対象は既定LIF、段階2、段階4A。外部データを新たに使わず、設定・採点・コードを今回の結果より前のコミットに記録する。

- H1は既存の枯渇条件にGPiのバイアス低下を加える。H2は同じ枯渇条件でGPe→GPiの重みを2倍にする。以前の12シードの集計で、H1のGPi細胞発火率の中央値がH2と等しくなるバイアスを、隣接する2設定の間で線形補間する。外挿と今回のシードでの再調整は行わない。この較正は病態データで観測した低下の大きさへの適合ではない。
- 今回の12シードそれぞれで、1,000細胞・19,680辺、1 ms刻み。各モデル内で位置・配線・初期条件・雑音を共有する。正常、既定枯渇（PD）、H1、H2の全条件で、GPiに入るすべての負のシナプス重みを開始時から0%、25%、50%、75%、100%減衰させる。薬剤、受容体、拡散はモデル化しない。
- 初めの0.5秒を除いた6秒間で、無発火も含めGPi全180細胞の発火率の中央値を求める。各シードで各仮説の遮断応答を「遮断時 − 同じ仮説の0%時」、応答差を「H2の遮断応答 − H1の遮断応答」とする。区間はシードをペアごとに1万回再抽出した平均の95%パーセンタイル区間。シードは動物個体を表さない。
- 主判定は50%遮断。0%時のH2−H1差の区間全体が±1 Hz以内、かつ50%の応答差の区間下限が+2 Hzを超えるモデルを通過とする。閾値は今回の計算実験用。全3モデルの成否を個別に報告する。補助解析では残りの遮断率、および遮断率を等しくできない場合（H2が25%、H1が75%と、その逆）の応答差を示す。5水準のうち差の大きい水準を主判定に変更しない。
- 健常条件と既定枯渇の応答を併記する。実装の対照として、同じ枯渇状態の3条件でGPi以外の発火列が一致し、100%遮断ではH2と既定枯渇のGPi発火列も完全に一致することを検査する。GPiは出力専用なので後者は定義から期待される。

設定は [protocol.json](protocol.json)。再現はリポジトリ直下で以下を実行する。

```sh
python -m partial_block.run --out reproduced_partial_block --workers 3
```
