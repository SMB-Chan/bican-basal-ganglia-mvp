# 開ループのGPe–STN回路でPD特異的な8〜15 Hz振動が出るか（探索、事前登録）

段階4Bでは、どのモデルでもPD状態の8〜15 Hz振動が出なかった。その原因として「皮質―視床の帰還ループが必要」と書いたが、検証はしていない。同じモデル族でも、GPe⇄STNループの利得が足りないだけという別の説明が残る。STN–GPe局所回路で振動が生じるとする計算モデルの報告もある。ここでは、新しい外部データを使わずに、この2つを切り分ける。

## 設計

段階4Aの凍結モデル（[`selection.json`](../rebound/results/selection.json)）を基に、次の3つだけを変える32条件を作る。

- GPe→STNの辺の重み：1、2、3、4倍
- STN→GPeの辺の重み：1、2、3、4倍
- STNのリバウンド：75 mV（凍結値）、0 mV

各条件で、正常状態のGPe・STN・GPiのバイアスを較正シード800で再設定し、発火率を凍結モデルの目標値（[`calibration.json`](../rebound/results/calibration.json)）にそろえる。これにより、ループの利得は平均の駆動ではなくリズムだけを変える。ドーパミン枯渇の操作とスペクトル解析は [段階4B](../parkinsonian/PROTOCOL.md) と同じ。新しい12シード（2297〜2381）で、正常状態とPD状態の自発活動を比べる。

## 判定（[`protocol.json`](protocol.json)。この文書とコードは実行前にコミットした）

- **シードごとのPD特異的振動**：PD状態のSTNとGPiの振動指数がともに1.5以上で、正常状態の1.25倍以上。かつ正常状態のSTNの指数が1.5未満。
- **陽性の条件**：12シード中6シード以上でPD特異的振動が出る。
- 較正の失敗（目標から2 Hz超ずれる）は除外せずに報告する。

## 解釈の規則

1. 陽性の条件がなければ、この範囲の開ループ回路ではPD特異的振動は出ない。皮質―視床の帰還が必要という仮説と矛盾しないが、証明にはならない。
2. 陽性の条件があれば、このモデル族で「閉ループが必要」という主張は撤回し、陽性の領域をループ利得についての仮説として報告する。
3. どちらの結果も、Tachibanaら（2011）との一致には数えない。その薬理実験は段階4Bで使用済み。

## 再現手順

```powershell
python -m oscillation.run --out oscillation_run
python -m oscillation.analyze oscillation_run
```

実行前の試運転は、凍結モデルと同じ1条件だけを、確認用ではないシード2003で行い、コードが動くことだけを確かめた。
