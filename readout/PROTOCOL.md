# 8〜15 Hz振動指数の陽性対照（事前登録）

段階4Bのテスト2は、STNとGPiの両方で振動指数が1.5以上になることを求めた。[開ループの探索](../oscillation/RESULTS.md)では、STNの指数は1.5を超えることがあったが、GPiの指数は正常状態でも0.3台にとどまった。GPiでの1.5という基準が、このモデルでそもそも到達できるのかを、既知の12 Hzのリズムを外から与えて確かめる。外部データは使わない。

## 設計

段階4Aの凍結モデル、正常状態とPD状態（[段階4B](../parkinsonian/PROTOCOL.md) と同じドーパミン枯渇操作）、新しい12シード（2383〜2467）。

- **STNに与える条件：** STNの全細胞の平衡電位を、共通の位相で12 Hz・振幅A mVで揺らす。Aは0.5、1、2、4、8 mV。
- **GPiに直接与える条件：** 同じ操作をGPiの全細胞に行う。
- **孤立GPi：** 同じシードのGPi細胞から全シナプスを外し、リズムなしで測る。指数の細胞自身の水準を知るため。

11条件（リズムなし、STN 5段階、GPi 5段階）を同じ雑音で並べて計算する。スペクトル解析は段階4Bと同じ。

## 判定（[`protocol.json`](protocol.json)。この文書とコードは実行前にコミットした）

- **R1 STN経由でGPiが基準に届く：** PD状態で、STNの指数（12シード平均）が1.5以上になる振幅のいずれかで、GPiの指数も1.5以上。
- **R2 GPiの指数が振動を捉えられる：** PD状態でGPiに直接与えたとき、8 mVまでのいずれかの振幅でGPiの指数が1.5以上。

| 結果 | 解釈 |
|---|---|
| R2が不合格 | このモデルではGPiの指数が1.5に届かない。段階4Bのテスト2のGPiの部分は、設計上満たせなかった |
| R2が合格、R1が不合格 | 指数は機能するが、回路がSTNのリズムをGPiの集団活動に伝えない |
| R1・R2とも合格 | GPiの基準は到達可能。段階4Bの失敗は、凍結したループ利得でSTNのリズムが出ないことによる |

試運転は、確認用ではないシード2003で、PD状態の振幅0と8 mVだけを流し、出力の行数だけを確かめた（値は見ていない）。

```powershell
python -m readout.run --out readout_run
python -m readout.analyze readout_run
```
