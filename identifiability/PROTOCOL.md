# 段階1　同じ出力を与える配線を数える

## 配線と入力の固定・変更

1,000ニューロン・19,680有向辺に固定する。4種類のMRIマスク内配置を作り、各配置に16個の配線乱数を適用する。各配置では細胞型、座標、背景の乱数、初期電位、刺激するSTN細胞を固定する。同じ型の配線では、発信細胞の出次数、興奮・抑制の符号と本数、距離カーネル、許可した方向付き経路と辺の重みを共通にして、標的細胞だけを引き直す。Eは前回と同じ仮定の膜特性、FはD1・D2のPatch-seq膜時定数中央値。EとFは同じ有向グラフを使う。

基準の経路別オッズでは、STN→GPeとSTN→GPiを2対2にする。さらに4対1と1対4の二つの仮説を比較する。正の投射方向は全部共通で、これらの数値は投射オッズの仮定。標的群のサイズと距離も効くため、オッズと実現された接続割合は別に記録する。各仮説で64グラフ、合計192グラフを生成し、EとFの計384条件で評価する。

## 評価指標

定常発火率と発火間隔CVをGPe・STN・GPiで測る。前回と同じSTN単発刺激を用い、遮断前後それぞれで同じ乱数の無刺激応答を差し引く。8反復、1 ms刻みで計70 msを保存。4項目の符号判定は、早期興奮、後期抑制、STN→GPe遮断時の早期興奮の残存、遮断による後期抑制の減弱。生体の参照データ、時間窓、刺激と遮断の近似は前のプロトコルと共通。合成二択は段階1の指標から外した。 [元の外部評価と出典](../validation/PROTOCOL.md)

**同じ出力の判定。** 同一配置・膜条件で、同じ仮説から得た別々の配線をすべて比較する。別の仮説同士の場合は乱数番号を揃える。符号については4つの真偽値がすべて一致するかを比較する。連続値は、3領域の発火率がそれぞれ2 Hz以内、CVがそれぞれ0.10以内、遮断前後の早期応答がそれぞれ1.0 Hz以内、後期応答がそれぞれ0.5 Hz以内のすべてを満たす場合に近いと数える。閾値はこの比較用の許容差で、動物間の測定誤差として推定した値ではない。グラフのJaccard類似度は、共通の有向辺数を、どちらかに存在する有向辺数で割る。

**外部記録に照らした同時条件。** 定常発火率の3領域平均絶対誤差が5 Hz以下、かつ4項目の符号が全一致するグラフを数える。さらに遮断後の後期GPi応答の絶対値0.5 Hz以下を加えた場合も数える。0.5 Hzは原著が示した抑制消失を近似するための作業上の閾値。両方の数は、今回サンプリングしたモデル内の候補数であり、実測に適合する全配線数の推定には使わない。CVは引き続き別指標として報告する。

**投射仮説の判別。** 符号のみ、定常活動と時間窓の連続値、さらに遮断前後の波形を追加した3種類を比較。単純な最近傍重心法を使い、訓練データだけで尺度を標準化する。保持した1配置と1組の配線乱数を両方とも訓練から除外する。乱数は番号の偶奇で二分して全テスト行を一度ずつ評価する。同点は均等配点。3仮説の均等ランダム分類は33.3%。報告値は指定した3仮説を生成済みモデル内で区別する成績で、実際の脳の投射を同定した成績ではない。

## 再現手順

プロジェクト直下で実行する。MRI入力は同梱。新しい外部データの取得は不要。

```powershell
python -m unittest -v
python -m identifiability.run --out identifiability_reproduced
python -m identifiability.analyze identifiability_reproduced
```

`--placements 701` で単一配置の動作を確認できる。`evaluations.csv` は各評価、`pairs.csv` は比較した対、`response_arrays.npz` は `evaluations.csv` と同じ順序で格納した刺激波形、`discrimination_folds.csv` と `discrimination_confusion.csv` は保持した配置と乱数ごとの判別結果。入力と出力のハッシュおよび全設定は `manifest.json` に記録した。
