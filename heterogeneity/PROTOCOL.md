# 実測した細胞ごとの膜特性を使う追加実験

前の実験では、D1・D2の膜時定数を各群の中央値に置き換えた。今回は細胞ごとのばらつきと、同一細胞で共変する特性を段階的に加える。**配線と位置を固定したまま膜特性だけを変更した場合**の効果を、既知投射を使う配線と使わない配線で確かめる。並行して、細胞自体の発火しやすさを測った切片実験をドナー単位で検証する。

## 実測データと抽出

Allen Institute for Brain Science / HMBA-BICAN `HMBA-Macaque-PatchSeq/20260228` の公開ファイルを使用。`cell_label` と `donor_label` で、背側線条体D1/D2 SPNの細胞型分類、膜特性、活動電位の特徴、ドナーの種を対応付ける。MapMyCellsでサブクラス・グループの両ブートストラップ確率が0.8以上の細胞が対象。以下の3特性を同じ細胞で取得でき、範囲確認を通過した行を使用する。 [Cell原著](https://doi.org/10.1016/j.cell.2026.10.028) · [測定方法の公開稿](https://pmc.ncbi.nlm.nih.gov/articles/PMC13160158/) · [公式配布](https://alleninstitute.github.io/abc_atlas_access/descriptions/HMBA-Macaque-PatchSeq-BG.html)

| 特性 | 配布データの列 | 利用範囲 |
|---|---|---|
| 膜時定数 τ | `cross_sweep_long_square_features.csv` の `tau`。秒をmsに換算。 | 1–100 ms |
| 静止電位から発火閾値までの差 ΔV | `ap_features.csv` の `threshold_v_short_square` から `v_baseline` を引く。静止電位は−95〜−55 mVに限定。 | 10–75 mV |
| 定常入力抵抗 R | `cross_sweep_long_square_features.csv` の `input_resistance_ss`。過分極時の定常応答から推定。 | 10–300 MΩ |

これらは切片で得た測定。アカゲザルとブタオザルをまとめた条件を主解析とし、アカゲザルだけで置き換える条件を種の感度確認に入れた。測定した細胞とドナーの数、中央値・四分位範囲・Pearson相関は `results/cell_cohort.csv` に記録した。元ファイルはローカルのキャッシュに置く。同梱するのは集計値、条件、出典、SHA-256。配布データは **CC BY-NC 4.0**。 [データ利用条件](https://alleninstitute.github.io/abc_atlas_access/descriptions/HMBA-Macaque-PatchSeq-BG.html) · [ライセンス](https://creativecommons.org/licenses/by-nc/4.0/)

## 回路で比較した条件

1,000ニューロン、19,680接続、同一シード内の座標・グラフ・初期電位・試行入力を固定。距離＋細胞型による配線（前回のC）と、既知投射のマスクと経路別オッズを加えた配線（前回のE）を別々に評価した。両方とも同チャネル選好を使わない。先行実験と重複しない12シードで、各配線に次の6条件を適用した。

| 条件 | D1・D2の膜特性 |
|---|---|
| Original | MVPの固定値を使う。 |
| Median τ | 今回の完全データ群で得た群ごとの中央値を使う。 |
| Variable τ | 同群の細胞行を復元抽出し、τのみ変える。 |
| Shuffled traits | 同じ抽出行から3特性を使い、ΔVとRは群内で独立に並べ替える。 |
| Paired traits | 同じ抽出行の3特性を、その組み合わせのまま使う。Shuffledと各特性の値の集合は一致する。 |
| Rhesus only | アカゲザルの行のみでPaired traitsを再構成する。種の効果と抽出標本の違いが含まれる。 |
| Shuffled, mean-matched | Shuffled traitsの各SPN群の閾値を一律にずらし、平均の興奮性をMedian τにそろえる（追加の対照）。 |
| Paired, mean-matched | Paired traitsに同じ操作をする（追加の対照）。 |

**平均の興奮性をそろえる対照。** ばらつきを入れると、群の中央値を保っていても平均の発火率は変わりうる。この影響を分けるため、D1・D2それぞれで閾値に共通の定数を足す。定数は二分法（−15〜+15 mV、25回）で決め、シナプスなしの孤立状態で群の平均発火率が同じシードのMedian τ条件と一致するようにする。孤立時の比較は3,000 ms（最初の300 msを除外）で、両条件に同じ雑音の乱数列を使う。目標値はモデル内部の量で、外部記録は使わない。細胞間の閾値差、τ、入力倍率、特性の組み合わせは変えない。ずらし幅は `results/rate_matching.csv` に記録する。ネットワーク内のD1・D2の発火率も各条件で記録するが、外部評価の誤差には含めない。

ネットワークの発火閾値は、群のΔV中央値に対する比を元の15 mVの閾値差に掛ける。定常バイアスと課題入力は、群のR中央値に対する比で倍率を変える。これにより群の基準値を維持して、切片と生体内で異なりうる範囲をそのまま移植せずに個体差を取り込む。この変換自体はモデル上の仮定。シナプスの電位ジャンプ・リセット電位・不応期は共通。τだけはmsの実測値を直接使う。細胞特性の割り当てはMRIマスク内の位置と独立で、実測細胞の空間勾配は扱わない。

定常発火率、発火間隔のばらつき、視床下核刺激への応答、合成二択の採点法は前回と同じ。発火率と介入応答の外部記録はパラメータ選択のために最適化していないが、この段階では既知の参照を継続利用している。結果を外部の新規実験への盲検予測とは解釈しない。平均と対応差の95%区間はシードを5,000回再抽出して計算する。 [前の検証手順と原著](../validation/PROTOCOL.md)

## 取り分けたドナーでの細胞単位の検証

同一データ内の別の測定として、長い電流ステップで発火を起こす最小電流（`rheobase_i`、pA）を予測した。閾値の入力には短い別の電流ステップの値を用い、長いステップの発火閾値は使わない。予測対象の細胞でも入力特性は利用できる設定。各ドナーを順番に取り分け、そのドナーの応答値を較正から外した。

- **細胞型の中央値**は残りのドナーの実測rheobaseの中央値。細胞型ごとの基準。
- **受動膜式**は測定した各細胞の `1,000 × ΔV / R`（pA）。長い電流ステップに対する線形受動膜の近似で、順応や電位依存性を表さない。
- **較正付き受動膜式**は同じ予測に倍率を掛ける。倍率は訓練ドナーの実測値／受動膜式の中央値。D1/D2別に推定し、取り分けたドナーに適用する。

各ドナーで細胞平均を求め、ドナー間を等加重して報告する。95%区間は各ドナーの誤差、または対応差を5,000回再抽出した記述的な区間。ネットワーク側の指標やパラメータには、このrheobaseの予測値を使っていない。

## 再現手順

プロジェクト直下で前回と同じPython環境を使う。初回のみアトラス以外のPatch-seq原本を取得する。

```powershell
python -m unittest -v
python -m heterogeneity.run --fetch --cache patchseq_cache --out heterogeneity_reproduced
python -m heterogeneity.analyze heterogeneity_reproduced
```

短時間の確認には `--seeds 307` で1シードを指定できる。`network.csv` はシード別の指標とグラフのハッシュ、`tonic.csv` は領域別発火、`donor_validation.csv` は元のドナーIDを含まないドナー内集計。`*_paired.csv` は対応差、`manifest.json` は設定と元データ・出力のハッシュ。これらは `results/` に保存した。
