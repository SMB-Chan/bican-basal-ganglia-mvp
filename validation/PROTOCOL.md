# 生物学的制約を追加したときの機能検証

## 比較設計

前回と同じ1,000細胞・19,680有向接続を使う。GPi以外の各ニューロンは24本の出力を持ち、細胞型構成、出力の符号と強度、共通乱数、背景入力を揃える。AからGでは細胞位置を各シードで共通にし、下表の順に追加する。Aのランダム配線でも、個々の辺の伝導遅延には距離を使う。

| 条件 | 追加する制約 |
|---|---|
| A | ランダム配線を基準とする。 |
| B | 短距離の辺を優先する。 |
| C | 細胞型ペアの局所親和度を加える。 |
| D | 文献に基づく有向経路マスクを加える。許可された経路の追加倍率はすべて1で、距離と局所親和度は維持する。 |
| E | 経路別の接続オッズの仮定を加える。 |
| F | D1・D2 SPNの膜時定数を各群18 msからPatch-seqの各群中央値に置き換える。残りの細胞特性は共通。 |
| G | 特定経路の同チャネル標的に4倍のオッズを与える。課題チャネルは合成ラベル。 |

追加対照は3つ。`E_channel` はEに同チャネル選好だけを加えた旧MVPのD相当。`E_gaussian` と `F_gaussian` はEとFのMRIマスクを、領域別の重心と共分散に合わせた3次元ガウス分布に置き換える。MRI領域の大まかな位置と広がりを両方が使うため、比較対象はマスク形状など高次の空間構造。ガウス側では領域境界を越える座標を許す。Patch-seqとMRI形状の効果、Patch-seqと同チャネル選好の効果を、対応比較用にそれぞれ組み合わせた。

## 設定用データと評価用データ

**設定用**のMRI領域マスクと投射方向の出典は [MVPのデータ出典](../SOURCES.md)。Patch-seqはAllen Institute for Brain Science / HMBA-BICANの `HMBA-Macaque-PatchSeq/20260228`。背側線条体のD1/D2 MSNの両カテゴリに対し、MapMyCellsでグループ・サブクラスのブートストラップ確率が共に0.8以上の細胞を抽出。`cell_label` で膜特性と結合した。用語表で `tau` の単位が秒であることを確認し、1–100 msを採用範囲として外れ値を除いた。細胞単位で中央値を求め、群内の全モデル細胞に同じ値を割り当てる。列、抽出条件、取得元、ハッシュは [`patchseq_tau.json`](patchseq_tau.json) に記録。元ファイルは再取得方式で、同梱するデータは要約・出典・利用条件。モデル上の異種細胞、基礎バイアス、シナプスジャンプ、伝導遅延、選択課題チャネルは依然として仮定。切片の膜時定数を生体内LIFに転用することも別の仮定。 [Liu・Chartrandらの原著](https://doi.org/10.1016/j.cell.2026.10.028) · [公式配布・CC BY-NC 4.0](https://alleninstitute.github.io/abc_atlas_access/descriptions/HMBA-Macaque-PatchSeq-BG.html) · [ライセンス](https://creativecommons.org/licenses/by-nc/4.0/)

**外部評価1・定常活動。** Gatev & Wichmannの表1にある正常覚醒状態の3個体（U、G、Y）を等加重。GPe・STN・GPiそれぞれの定常発火率および細胞ごとの発火間隔の変動係数（CV）を参照する。モデルは刺激なし2秒、最初の300 msを除外。CVは6スパイク以上（5間隔以上）の細胞を使い、有効割合も保存。各領域を等加重して平均絶対誤差（MAE）を計算する。原著のGPeは高頻度発火細胞を選択しているため、モデル群との対応は近似。 [覚醒アカゲザルの原著と表1](https://pmc.ncbi.nlm.nih.gov/articles/PMC2677649/#T1)

**外部評価2・介入。** Kitaらが報告したSTN単発刺激後のGPi応答を評価する。原著のGPi興奮は平均開始3.9 ms、平均持続9.3 ms。続く抑制は平均開始13.9 ms、平均持続40.3 ms。GPe内で薬理的に刺激応答を遮断すると、抑制が消え、主に早期興奮が残った。モデルでは300 ms時点で、全条件で対応するSTNの半数に12 mVの単発電位ジャンプを与え、STN→GPeの辺の効果をゼロにした場合とも比較。これは薬理操作の簡略化で、刺激を電流・組織拡散まで再現していない。同じ雑音と初期電位による無刺激対照を、それぞれの配線・介入条件で差し引く。各グラフで12反復。時間窓は原著に基づき早期3–13 ms、後期14–54 ms（どちらも終端を除く）。 [Kitaらの原著、単発刺激の結果と図5・7](https://pmc.ncbi.nlm.nih.gov/articles/PMC6725523/)

介入の評価は、早期興奮、後期抑制、遮断時の早期興奮の残存、遮断による後期抑制の減弱を、各シードにつき1点ずつ数える。実用上の符号閾値は0.25 Hz。スコアと併せ、各窓の符号付き発火率差と1 ms平均波形を保存する。検証対象は群平均で、原著の単一細胞ごとの応答型の頻度を再現判定していない。

**補助評価・合成二択。** 前回MVPの2/5 mV差を使い、各差・各側4試行。同チャネル選好が二択スコアに寄与するかを見る。動物の行動成績の照合には使用しない。

## 評価単位と再現

既存の6シードと重複しない12シードを使用。各条件の平均と対応差の95%パーセンタイル区間は5,000回のシード再抽出で算出する。区間は合成ネットワークと確率的入力に由来する変動を表す。動物間の不確かさや複数比較による誤差を表さない。モデルの数値パラメータを外部の発火率や刺激応答に合わせて最適化する工程は設けていない。刺激の評価窓は原著を参照して決めた。定常・介入・合成二択は測っている対象が異なるため、結果はそれぞれの指標で読む。

プロジェクト直下でMVPと同じ環境を使って実行する。

```powershell
python -m unittest -v
python -m validation.run_validation --out validation_reproduced
python -m validation.analyze_validation validation_reproduced
```

短い確認は `--seeds 101` を追加する。膜時定数の要約を配布元から作り直すコマンドは以下。

```powershell
python -m validation.prepare_patchseq --fetch --cache patchseq_cache --out patchseq_reproduced.json
```

`results/metrics.csv` にグラフと機能指標、`tonic.csv` に部位別発火率とCV、`pulse_curves.csv` に刺激波形、`summary.csv` と `paired.csv` にシード集計と区間、`manifest.json` に設定・入力・出力ハッシュを保存した。
